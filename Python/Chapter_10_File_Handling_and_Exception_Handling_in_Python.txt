CHAPTER 10: FILE HANDLING AND EXCEPTION HANDLING IN PYTHON

File handling and exception handling are two important topics in Python programming. They help us build programs that can store data permanently, retrieve information, manage files, and handle errors without crashing unexpectedly.

For Python learning, especially in data science and data analytics, these concepts are essential because datasets, CSV files, text files, and other data sources are used frequently.


PART 1: FILE HANDLING IN PYTHON

1. WHAT IS FILE HANDLING?

File handling is the process of creating, opening, reading, writing, appending, and closing files using a programming language.

Normally, variables store data temporarily while a program runs. When the program terminates, that data is generally lost. File handling allows us to save data on a storage device so that it can be used later.

For example, suppose you create a Python program to store students' names and marks. If you only use variables, the information may disappear when the program ends. If you save the information in a file, you can retrieve it the next time you run the program.

Real-world applications:
- Storing student records and examination results.
- Saving application logs and error messages.
- Reading datasets for data analysis.
- Storing configuration settings.
- Creating reports and exporting results.
- Saving information generated by a program.


2. TYPES OF FILES IN PYTHON

Python programs commonly work with two broad categories of files.

A. TEXT FILES

Text files store information as readable characters.

Examples: .txt, .csv, .py, .log, and many .json files.

Example content:
Name: Saurav

B. BINARY FILES

Binary files store data as bytes and are not generally intended to be read directly as ordinary text.

Examples: images (.jpg, .png), audio (.mp3), PDFs, and executable files.

Python can work with both types. The main difference is whether the file is handled as text or as bytes.


3. BASIC STEPS OF FILE HANDLING

Most file-handling operations follow these steps:

1. Open a file: Choose the file and access mode.
2. Perform an operation: Read, write, append, or process data.
3. Close the file: Release the file resource.


4. THE open() FUNCTION

The open() function opens a file and returns a file object that allows us to work with it.

Syntax:

file_object = open("filename.txt", "mode")

Explanation:
- open() is the built-in function.
- "filename.txt" is the name or path of the file.
- "mode" specifies what operation you want to perform.
- file_object is the variable that refers to the opened file.

Example:

file = open("example.txt", "r")

This opens example.txt in read mode. The file must already exist, or Python will normally raise a FileNotFoundError.


5. FILE OPENING MODES

The mode determines how Python accesses a file.

Mode "r" — Read:
Reads an existing file; fails if it does not exist.

Mode "w" — Write:
Creates a file or truncates an existing file, removing its previous content.

Mode "a" — Append:
Adds content to the end; creates the file if needed.

Mode "x" — Exclusive creation:
Creates a new file; fails if it already exists.

Mode "b" — Binary:
Handles data as bytes, often combined with another mode.

Mode "t" — Text:
Handles data as text; this is the default mode.

Mode "r+" — Read and write:
Requires an existing file and does not initially truncate it.

Mode "w+" — Write and read:
Creates or truncates a file.

Mode "a+" — Append and read:
Creates the file if needed; writing is directed to the end.

Examples of combined modes include "rb", "wb", and "ab".

IMPORTANT:
Be careful with "w" and "w+" because opening an existing file in these modes truncates its contents.


6. READING FILES IN PYTHON

Python provides several methods for reading data from a file.

First, create a file named student.txt containing:

Name: Saurav
Course: BSc CSIT
College: Asian College


A. read() METHOD

The read() method reads the contents of a file and returns them as a string in text mode.

Example:

file = open("student.txt", "r")

content = file.read()

print(content)

file.close()

Output:

Name: Saurav
Course: BSc CSIT
College: Asian College

Explanation:
1. open() opens the file in read mode.
2. read() reads the file's contents.
3. print() displays the contents.
4. close() closes the file.

You can also specify how many characters to read.

Example:

file = open("student.txt", "r")

print(file.read(4))

file.close()

Output:

Name

Here, read(4) reads up to four characters from the current file position.


B. readline() METHOD

The readline() method reads one line at a time.

Example:

file = open("student.txt", "r")

print(file.readline())
print(file.readline())

file.close()

Output (a blank line may appear between lines):

Name: Saurav

Course: BSc CSIT

The extra blank line in the output occurs because each line read normally includes its newline character, and print() adds another newline.

You can remove that extra line using strip():

file = open("student.txt", "r")

print(file.readline().strip())
print(file.readline().strip())

file.close()

Output:

Name: Saurav
Course: BSc CSIT


C. readlines() METHOD

The readlines() method reads all remaining lines and returns them as a list of strings.

Example:

file = open("student.txt", "r")

lines = file.readlines()

print(lines)

file.close()

Output:

[
    'Name: Saurav\n',
    'Course: BSc CSIT\n',
    'College: Asian College\n'
]

The \n represents a newline character.

You can iterate through the list to display each line:

file = open("student.txt", "r")

lines = file.readlines()

for line in lines:
    print(line.strip())

file.close()

Output:

Name: Saurav
Course: BSc CSIT
College: Asian College


DIFFERENCE BETWEEN READING METHODS

read():
- Reads all remaining content or a specified number of characters.
- Returns a string.

readline():
- Reads one line.
- Returns a string.

readlines():
- Reads all remaining lines.
- Returns a list of strings.

For very large files, reading everything into memory at once can be inefficient. Iterating over the file line by line is usually preferable.

Example:

with open("student.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())

This approach processes one line at a time.


7. WRITING FILES IN PYTHON

The write() method writes a string to a file.

Example: Writing student information

file = open("student.txt", "w")

file.write("Name: Saurav\n")
file.write("Course: BSc CSIT\n")
file.write("College: Asian College\n")

file.close()

The file will contain:

Name: Saurav
Course: BSc CSIT
College: Asian College

Explanation:
- "w" opens the file in write mode.
- write() writes a string to the file.
- \n moves the next content to a new line.
- close() closes the file and ensures buffered data is flushed.

If student.txt already contains data, opening it in "w" mode removes the existing content before writing the new information.


IMPORTANT: write() DOES NOT AUTOMATICALLY ADD A NEWLINE

Consider this code:

with open("example.txt", "w") as file:
    file.write("Hello")
    file.write("Python")

File content:

HelloPython

To place the words on separate lines:

with open("example.txt", "w") as file:
    file.write("Hello\n")
    file.write("Python\n")

File content:

Hello
Python


WRITING MULTIPLE LINES WITH writelines()

The writelines() method writes an iterable of strings to a file.

Example:

lines = [
    "Name: Saurav\n",
    "Course: BSc CSIT\n",
    "College: Asian College\n"
]

with open("student.txt", "w", encoding="utf-8") as file:
    file.writelines(lines)

Remember:
writelines() does not automatically insert newline characters. Include \n in the strings if you want separate lines.


8. APPENDING DATA TO A FILE

Appending means adding new information without deleting the existing contents.

The "a" mode is used for this purpose.

Example:

with open("student.txt", "a", encoding="utf-8") as file:
    file.write("Semester: Third\n")

If the file previously contained:

Name: Saurav
Course: BSc CSIT

It will now contain:

Name: Saurav
Course: BSc CSIT
Semester: Third

Unlike "w", append mode preserves the existing content and writes new content at the end.


PRACTICAL EXAMPLE: STUDENT MARKS RECORD

with open("marks.txt", "w", encoding="utf-8") as file:
    file.write("Saurav: 85\n")

with open("marks.txt", "a", encoding="utf-8") as file:
    file.write("Ram: 90\n")
    file.write("Hari: 78\n")

with open("marks.txt", "r", encoding="utf-8") as file:
    print(file.read())

Output:

Saurav: 85
Ram: 90
Hari: 78

This example demonstrates writing, appending, and reading in a single program.


9. CLOSING A FILE

The close() method closes an opened file.

Example:

file = open("example.txt", "r")

print(file.read())

file.close()

Closing files is important because it:
- Releases system resources.
- Flushes buffered output when applicable.
- Helps prevent resource leaks.
- Avoids leaving files unnecessarily open.

However, if an exception occurs before close() executes, the file might remain open longer than expected. Python provides a better approach called the with statement.


10. THE with STATEMENT

The with statement is the recommended approach for most file operations because it automatically closes the file when the block ends, including when an exception occurs.

Syntax:

with open("filename.txt", "mode") as file:
    # Perform file operations
    pass

Example:

with open("student.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)

There is no need to call file.close() manually.

Why is this better?
Suppose a program encounters an error while reading a file. With a properly used with statement, Python still closes the file when control leaves the block.


11. FILE POSITION: tell() AND seek()

Python maintains a current position within an open file.

A. tell()

The tell() method returns the current file position, measured in bytes for binary files and according to the text stream's position rules for text files.

Example:

with open("example.txt", "r", encoding="utf-8") as file:
    print(file.tell())
    print(file.read(5))
    print(file.tell())

For a simple ASCII text file, the output might be:

0
Hello
5

The first position is at the beginning. After reading five ASCII characters, the position is five.

B. seek()

The seek() method moves the file position.

Example:

with open("example.txt", "r", encoding="utf-8") as file:
    print(file.read(5))

    file.seek(0)

    print(file.read(5))

Output, if the file begins with Hello:

Hello
Hello

Here, seek(0) moves the file position back to the beginning.

These methods are useful when you need to revisit parts of a file. Text-mode seeking has some restrictions; binary mode is often easier when working with exact byte positions.


12. WORKING WITH FILE PATHS

A file may exist in the current working directory or in another directory.

RELATIVE PATH

A relative path identifies a file in relation to the program's current working directory.

Example:

with open("student.txt", "r", encoding="utf-8") as file:
    print(file.read())

This works when student.txt is located in the current working directory.

ABSOLUTE PATH

An absolute path identifies the file using its full location.

On Windows:

with open(
    r"C:\Users\Student\Documents\student.txt",
    "r",
    encoding="utf-8"
) as file:
    print(file.read())

The r before the string makes it a raw string, which helps prevent backslashes from being interpreted as escape sequences.

On Linux or Kali Linux:

with open(
    "/home/kali/Documents/student.txt",
    "r",
    encoding="utf-8"
) as file:
    print(file.read())

Replace the example paths with the actual location of your file.

COMMON PATH PROBLEM

If Python cannot locate a file, it may raise:

FileNotFoundError

You can check the current working directory with:

import os

print(os.getcwd())

This helps explain why a relative file path might not work.


13. HANDLING BINARY FILES

Binary files should generally be opened in binary mode.

For example, to copy an image:

with open("photo.jpg", "rb") as source:
    data = source.read()

with open("photo_copy.jpg", "wb") as destination:
    destination.write(data)

Explanation:
- "rb" reads the original file as bytes.
- "wb" creates or truncates the destination file and writes bytes.
- data contains the binary contents of the image.

The copied file can be opened as an image if the copying operation succeeds and the original file is valid.

For large files, copy them in chunks instead of loading all their bytes into memory at once.


14. WORKING WITH CSV FILES

CSV stands for Comma-Separated Values. It is a common format for storing tabular data and is widely used in data science and data analytics.

Suppose students.csv contains:

Name,Age,Marks
Saurav,21,85
Ram,20,90
Hari,22,78

Python's built-in csv module can read it.

READING CSV DATA

import csv

with open("students.csv", "r", newline="", encoding="utf-8") as file:
    reader = csv.reader(file)

    for row in reader:
        print(row)

Output:

['Name', 'Age', 'Marks']
['Saurav', '21', '85']
['Ram', '20', '90']
['Hari', '22', '78']

Each row is returned as a list of strings.


READING CSV DATA USING COLUMN NAMES

import csv

with open("students.csv", "r", newline="", encoding="utf-8") as file:
    reader = csv.DictReader(file)

    for student in reader:
        print(student["Name"], student["Marks"])

Output:

Saurav 85
Ram 90
Hari 78

DictReader lets you access fields using their column names.


WRITING CSV DATA

import csv

students = [
    ["Name", "Age", "Marks"],
    ["Saurav", 21, 85],
    ["Ram", 20, 90],
    ["Hari", 22, 78]
]

with open("students_output.csv", "w", newline="", encoding="utf-8") as file:
    writer = csv.writer(file)
    writer.writerows(students)

This creates a CSV file with the supplied rows.

CSV is useful for exchanging data between Python, spreadsheet applications, and database systems. For larger analytical workflows, libraries such as pandas provide additional functionality.


PART 2: EXCEPTION HANDLING IN PYTHON

1. WHAT IS AN EXCEPTION?

An exception is an error condition that occurs while a program is executing and interrupts its normal flow.

Examples include:
- Dividing a number by zero.
- Opening a file that does not exist.
- Converting invalid text into an integer.
- Accessing a list index that is outside its valid range.
- Attempting to access a missing dictionary key.

Consider this program:

a = 10
b = 0

result = a / b

print(result)
print("Program completed")

Output:

ZeroDivisionError: division by zero

The division raises an exception. Unless it is handled, the remaining statements in that execution path do not run, so "Program completed" is not printed.

Exception handling allows a program to respond to expected error conditions in a controlled way.


2. WHAT IS EXCEPTION HANDLING?

Exception handling is a mechanism for detecting and responding to exceptions so that a program can recover when possible or terminate in a controlled manner.

Python mainly uses these keywords:
- try
- except
- else
- finally
- raise

Each has a particular purpose.


3. THE try AND except BLOCKS

The try block contains code that might raise an exception. The except block specifies how to respond if a matching exception occurs.

Syntax:

try:
    # Code that may raise an exception
    statements

except ExceptionType:
    # Code to handle that exception
    statements

Example: Handling division by zero

try:
    a = 10
    b = 0

    result = a / b

    print(result)

except ZeroDivisionError:
    print("Error: Cannot divide by zero.")

print("Program completed")

Output:

Error: Cannot divide by zero.
Program completed

Explanation:
1. Python executes the statements in the try block.
2. The division raises ZeroDivisionError.
3. Python skips the remaining statements in that try block.
4. The matching except block executes.
5. The program continues after the exception-handling structure.

This prevents the unhandled exception from terminating the program at that point.


4. COMMON EXCEPTIONS IN PYTHON

Python provides several built-in exception types.

ZeroDivisionError:
Cause: Division by zero.
Example: 10 / 0

ValueError:
Cause: Correct type but invalid value.
Example: int("hello")

TypeError:
Cause: Operation on incompatible types.
Example: "5" + 2

NameError:
Cause: Undefined variable name.
Example: print(total), when total is undefined.

IndexError:
Cause: Invalid sequence index.
Example: [10, 20][5]

KeyError:
Cause: Missing dictionary key.
Example: {"name": "Saurav"}["age"]

FileNotFoundError:
Cause: Requested file cannot be found.
Example: Opening a nonexistent file in "r" mode.

PermissionError:
Cause: Operation not permitted by the operating system.
Example: Reading a file without sufficient permission.

ImportError:
Cause: Import operation cannot be completed.
Example: An unavailable imported name or module.

AttributeError:
Cause: Object lacks the requested attribute.
Example: Calling an unavailable method on an object.

The exact exception depends on the operation and circumstances.


EXAMPLE: HANDLING ValueError

try:
    age = int(input("Enter your age: "))
    print("Your age is:", age)

except ValueError:
    print("Error: Please enter a valid whole number.")

If the user enters twenty, Python cannot convert it into an integer, so the except block handles the ValueError.

If the user enters 20, the program prints the age normally.


5. HANDLING MULTIPLE EXCEPTIONS

Sometimes different errors can occur in the same program. Python allows multiple except blocks to handle different exception types separately.

Example:

try:
    a = int(input("Enter first number: "))
    b = int(input("Enter second number: "))

    result = a / b

    print("Result:", result)

except ValueError:
    print("Error: Please enter valid integers.")

except ZeroDivisionError:
    print("Error: The second number cannot be zero.")

Possible output when the input is 10 and 0:

Enter first number: 10
Enter second number: 0
Error: The second number cannot be zero.

Possible output when the first input is abc:

Enter first number: abc
Error: Please enter valid integers.

Why use separate exception handlers?
They let you provide an appropriate response for each type of error rather than showing the same generic message for every problem.


6. HANDLING MULTIPLE EXCEPTIONS IN ONE except BLOCK

If you want to respond to multiple exception types in the same way, you can group them in a tuple.

Example:

try:
    number = int(input("Enter a number: "))
    result = 100 / number
    print(result)

except (ValueError, ZeroDivisionError):
    print("Invalid input or division by zero.")

This handles either a failed integer conversion or division by zero.

Use separate handlers when the errors require different responses.


7. THE else BLOCK

The else block executes only when the try block finishes without raising an exception.

Syntax:

try:
    # Risky operation

except SomeException:
    # Handle a matching exception

else:
    # Execute if no exception occurs in try

Example:

try:
    number = int(input("Enter a number: "))

except ValueError:
    print("Invalid input.")

else:
    print("You entered:", number)
    print("The conversion was successful.")

If the user enters 25, the output is:

Enter a number: 25
You entered: 25
The conversion was successful.

If the user enters hello, the output is:

Enter a number: hello
Invalid input.

The else block does not run when an exception occurs in the try block.

Why use else?
It separates the code that might fail from the code that should run only after that operation succeeds.


8. THE finally BLOCK

The finally block executes when control leaves the try/except structure, whether an exception occurred or not. It is commonly used for cleanup operations.

Syntax:

try:
    # Code that may fail

except SomeException:
    # Handle the error

finally:
    # Cleanup code

Example:

try:
    number = int(input("Enter a number: "))
    print("Number:", number)

except ValueError:
    print("Invalid input.")

finally:
    print("Execution finished.")

If the user enters 10:

Enter a number: 10
Number: 10
Execution finished.

If the user enters hello:

Enter a number: hello
Invalid input.
Execution finished.

The finally block executes in both cases.

It is often used to release resources, close connections, and perform cleanup. However, it is not an absolute guarantee under circumstances such as forced process termination or certain interpreter-level failures.


DIFFERENCE BETWEEN else AND finally

else:
- Runs if the try block finishes without an exception.
- Used for code that depends on success.
- Does not run if an exception occurs in try.

finally:
- Normally runs when control leaves the structure, whether or not an exception occurred.
- Used for cleanup and final actions.
- Normally runs even if an exception occurs in try.


9. USING try, except, else, AND finally TOGETHER

This example demonstrates all four blocks.

try:
    a = int(input("Enter first number: "))
    b = int(input("Enter second number: "))

    result = a / b

except ValueError:
    print("Error: Enter valid integers.")

except ZeroDivisionError:
    print("Error: Cannot divide by zero.")

else:
    print("Division result:", result)

finally:
    print("Division program finished.")

Example with valid input:

Enter first number: 20
Enter second number: 4
Division result: 5.0
Division program finished.

Example with division by zero:

Enter first number: 20
Enter second number: 0
Error: Cannot divide by zero.
Division program finished.

Example with invalid input:

Enter first number: abc
Error: Enter valid integers.
Division program finished.

The order of execution is important:
1. Python attempts to execute the try block.
2. If a matching exception occurs, the corresponding except block executes.
3. If no exception occurs, the else block executes.
4. The finally block normally executes when control leaves the structure.


10. THE raise KEYWORD

The raise keyword allows a programmer to raise an exception deliberately.

This is useful when an input violates a rule defined by the program.

Example: Checking a negative age

age = int(input("Enter your age: "))

if age < 0:
    raise ValueError("Age cannot be negative.")

print("Your age is:", age)

If the user enters -5, Python raises a ValueError with the message:

ValueError: Age cannot be negative.

Because the exception is not caught here, the program terminates at that point.


HANDLING A MANUALLY RAISED EXCEPTION

try:
    age = int(input("Enter your age: "))

    if age < 0:
        raise ValueError("Age cannot be negative.")

except ValueError as error:
    print("Error:", error)

else:
    print("Your age is:", age)

For input -5, the output is:

Enter your age: -5
Error: Age cannot be negative.

Here, raise creates the exception, while except catches it.

Important distinction:
Exception handling manages errors; it does not automatically correct invalid data. Your program must decide whether to ask for new input, skip a record, retry an operation, or stop.


11. THE as KEYWORD IN EXCEPTION HANDLING

The as keyword lets you assign the caught exception to a variable so that you can inspect its message.

Example:

try:
    result = int("hello")

except ValueError as error:
    print("An error occurred:", error)

Output:

An error occurred: invalid literal for int() with base 10: 'hello'

The variable error contains the exception object. Printing it normally displays the exception message.

This is useful when debugging and when logging meaningful error information.


12. HANDLING FILE ERRORS

File handling and exception handling work particularly well together because file operations can fail for several reasons.

A file might not exist, a program might lack permission to read it, or a device error might occur.

Example: Opening a missing file

try:
    with open("unknown.txt", "r", encoding="utf-8") as file:
        content = file.read()
        print(content)

except FileNotFoundError:
    print("Error: The requested file does not exist.")

except PermissionError:
    print("Error: You do not have permission to read this file.")

The program handles two specific file-related errors.

The with statement ensures that the file is closed if it was successfully opened and an error later occurs inside the block.


EXAMPLE: READING A FILE SAFELY

filename = input("Enter filename: ")

try:
    with open(filename, "r", encoding="utf-8") as file:
        content = file.read()

except FileNotFoundError:
    print("The file was not found.")

except PermissionError:
    print("Permission denied.")

else:
    print("File content:")
    print(content)

The program displays the file contents only if reading completes without an exception.


13. GENERIC EXCEPTION HANDLING

Python also allows a general handler:

try:
    number = int(input("Enter a number: "))
    result = 100 / number
    print(result)

except Exception as error:
    print("An error occurred:", error)

Exception is a common base class for most ordinary application exceptions.

This handler can catch both ValueError and ZeroDivisionError in this example.

However, avoid using a broad except Exception when a specific exception can be handled instead. Specific handlers make programs easier to debug and help avoid hiding unexpected problems.

Do not use a bare except: without a good reason, because it can also catch exceptions such as KeyboardInterrupt and SystemExit that applications often should allow to propagate.


PART 3: ADVANCED CONCEPTS AND BEST PRACTICES

1. CREATING A CUSTOM EXCEPTION

Python allows you to define your own exception classes when built-in exceptions do not clearly express a particular application error.

Example: Invalid marks

class InvalidMarksError(Exception):
    pass


def check_marks(marks):
    if marks < 0 or marks > 100:
        raise InvalidMarksError(
            "Marks must be between 0 and 100."
        )

    return "Valid marks"


try:
    marks = int(input("Enter marks: "))
    print(check_marks(marks))

except ValueError:
    print("Please enter a whole number.")

except InvalidMarksError as error:
    print("Error:", error)

If the user enters 120, the output is:

Enter marks: 120
Error: Marks must be between 0 and 100.

Explanation:
- class InvalidMarksError(Exception) defines a custom exception.
- raise InvalidMarksError(...) raises it when the condition is violated.
- except InvalidMarksError catches that particular exception.

Custom exceptions are useful in larger applications where domain-specific errors need to be distinguished from ordinary programming errors.


2. COMMON EXCEPTION-HANDLING MISTAKES

MISTAKE 1: USING try WITHOUT AN APPROPRIATE HANDLER

Incorrect:

try:
    result = 10 / 0

A try statement must have at least an except or finally clause.

Correct:

try:
    result = 10 / 0

except ZeroDivisionError:
    print("Cannot divide by zero.")


MISTAKE 2: CATCHING EVERY EXCEPTION UNNECESSARILY

Less desirable:

try:
    number = int("hello")

except Exception:
    print("Something went wrong.")

Better:

try:
    number = int("hello")

except ValueError:
    print("Please provide a valid integer.")

The specific handler communicates what went wrong and avoids masking unrelated errors.


MISTAKE 3: IGNORING AN EXCEPTION

Avoid silently ignoring errors:

try:
    process_data()

except Exception:
    pass

This makes debugging difficult and may hide data loss or incorrect results.

Instead, handle the expected error appropriately or record useful information and allow unexpected exceptions to propagate.


MISTAKE 4: USING EXCEPTIONS INSTEAD OF ORDINARY VALIDATION

If a program expects a positive number, check the condition explicitly.

number = int(input("Enter a positive number: "))

if number <= 0:
    print("The number must be positive.")
else:
    print("Valid number:", number)

You may still need exception handling around int() because the user could enter non-numeric text.


PART 4: COMBINING FILE HANDLING AND EXCEPTION HANDLING

This is one of the most useful practical examples because real programs frequently read files that might contain invalid data.


EXAMPLE: STUDENT MARKS ANALYZER

Suppose you have a file named marks.txt containing:

80
90
75
85
70

Your goal is to read the marks, calculate their average, and handle missing files or invalid records safely.

Program:

def calculate_average(filename):
    marks = []

    try:
        with open(filename, "r", encoding="utf-8") as file:
            for line_number, line in enumerate(file, start=1):
                value = line.strip()

                if not value:
                    continue

                try:
                    mark = float(value)

                except ValueError:
                    print(
                        f"Skipping invalid data on line "
                        f"{line_number}: {value}"
                    )
                    continue

                if not 0 <= mark <= 100:
                    print(
                        f"Skipping out-of-range mark on "
                        f"line {line_number}: {value}"
                    )
                    continue

                marks.append(mark)

    except FileNotFoundError:
        print("Error: Marks file not found.")
        return None

    except PermissionError:
        print("Error: Permission denied.")
        return None

    if not marks:
        print("No valid marks found.")
        return None

    average = sum(marks) / len(marks)
    return average


result = calculate_average("marks.txt")

if result is not None:
    print(f"Average marks: {result:.2f}")

Average marks: 80.00


HOW THE PROGRAM WORKS

1. The function accepts a filename as an argument.
2. The try block opens the file.
3. The with statement ensures the file is closed automatically.
4. The loop reads the file one line at a time.
5. strip() removes surrounding whitespace and newline characters.
6. float() converts each valid mark into a numeric value.
7. The inner try/except handles invalid numeric records without stopping the entire analysis.
8. The range check skips marks outside 0–100.
9. The outer except blocks handle missing files and permission errors.
10. The function calculates and returns the average of valid marks.
11. The final if statement displays the result only if an average was returned.

For example, if the file contains 80, abc, 90, and 120, the program skips the invalid text and out-of-range mark, then calculates the average of 80 and 90.

This illustrates a key principle: handle errors at the level where you can make a sensible decision about recovery.


PART 5: FILE HANDLING VS. EXCEPTION HANDLING

FILE HANDLING:
- Works with files and stored data.
- Uses functions and methods such as open(), read(), write(), and close().
- Allows data to be saved and retrieved.
- Examples include reading a CSV file and writing a report.
- Helps with data persistence.

EXCEPTION HANDLING:
- Manages errors during program execution.
- Uses try, except, else, finally, and raise.
- Allows programs to respond to exceptional conditions.
- Examples include handling missing files and invalid input.
- Helps with reliability and controlled recovery.

The two concepts complement one another. File handling performs the data operation, while exception handling manages problems that may occur during that operation.


PART 6: QUICK REVISION NOTES

FILE HANDLING

- open() opens a file.
- "r" reads a file.
- "w" writes to a file and truncates existing content.
- "a" appends data.
- "x" creates a new file exclusively.
- read() reads content.
- readline() reads one line.
- readlines() returns remaining lines as a list.
- write() writes a string.
- writelines() writes multiple strings without adding newlines automatically.
- close() closes a file.
- with manages the file's lifetime automatically.
- seek() changes the file position.
- tell() reports the file position.

EXCEPTION HANDLING

- try contains code that may raise an exception.
- except handles matching exceptions.
- else runs if the try block finishes without an exception.
- finally normally runs when control leaves the structure.
- raise deliberately raises an exception.
- as assigns the caught exception to a variable.
- Custom exceptions represent application-specific errors.
