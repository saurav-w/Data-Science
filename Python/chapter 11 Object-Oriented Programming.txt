Object-Oriented Programming in Python
Object-Oriented Programming, or OOP, is a way of writing programs by organizing code around objects.
In OOP, we think of a program as a collection of real-world things, such as:
- a student
- a car
- a bank account
- a laptop
- a book

Each of these things has:
- data or properties such as name, age, color, price
- behaviors or functions such as study, drive, deposit, play
Python supports OOP very well, and it is one of the most important programming styles used in real software development.

1. What is Object-Oriented Programming?
OOP is a programming approach where we create classes and objects to represent real-world entities.
Instead of writing only functions and variables separately, we group related data and behavior together inside a class.

For example:
A Student has:
- name
- age
- grade
A Student can:
- study
- attend class
- take exam
This is a very natural way of designing programs.

2. Why Use OOP?
OOP is useful because it makes programs:
- easier to understand
- easier to maintain
- easier to reuse
- easier to modify
- more organized
It is especially helpful for large programs.
3. Main Concepts of OOP
The four main pillars of OOP are:
1. Class
2. Object
3. Encapsulation
4. Inheritance
5. Polymorphism
6. Abstraction
These are the most important ideas in object-oriented programming.
4. What is a Class?
A class is a blueprint or template for creating objects.
Think of a class like a design plan for a house.
The class tells us:
- what data an object will have
- what actions an object can perform
Example
class Student:    pass


Here, Student is a class.
The pass statement means “do nothing for now.”
5. What is an Object?
An object is an instance of a class.
If a class is a blueprint, then an object is the actual thing made from that blueprint.
Example
class Student:    passs1 = Student()


Here:
- Student is the class
- s1 is an object
6. Attributes and Methods
A class usually contains:
- attributes → data or properties
- methods → functions inside a class
Example
class Student:    name = "Saurav"    age = 21    def study(self):        print("Student is studying")


Here:
- name and age are attributes
- study() is a method
7. The self Keyword
self refers to the current object.
When we define methods inside a class, we use self as the first parameter.
Example
class Student:    def study(self):        print("Studying")


When Python calls the method, it automatically passes the object as self.
8. Creating Objects with Data
Usually, we want each object to have its own values.
For that, we use a special method called the constructor.

13. Inheritance
Inheritance allows one class to use the properties and methods of another class.
The new class is called the child class or derived class.
The original class is called the parent class or base class.
Example
class Person:    def __init__(self, name):        self.name = name    def show(self):        print(self.name)class Student(Person):    passs1 = Student("Saurav")s1.show()


Output
Saurav


Explanation
Student inherits from Person.
So Student can use the show() method from Person.
Why Use Inheritance?
- saves code
- improves reusability
- helps build relationships between classes
14. Types of Inheritance
Python supports several types of inheritance:
1. Single Inheritance
2. Multiple Inheritance
3. Multilevel Inheritance
4. Hierarchical Inheritance
5. Hybrid Inheritance
1. Single Inheritance
One child class inherits from one parent class.
class A:    passclass B(A):    pass


2. Multiple Inheritance
A child class inherits from more than one parent class.
class A:    passclass B:    passclass C(A, B):    pass


3. Multilevel Inheritance
A class inherits from another derived class.
class A:    passclass B(A):    passclass C(B):    pass


4. Hierarchical Inheritance
More than one child class inherits from the same parent class.
class A:    passclass B(A):    passclass C(A):    pass


15. Polymorphism

When a child class gives its own version of a parent class method, it is called method overriding.
Example
class Parent:    def show(self):        print("Parent class")class Child(Parent):    def show(self):        print("Child class")c = Child()c.show()


Output

16. Abstraction
Abstraction means hiding unnecessary details and showing only the important parts.
For example, when you drive a car, you use:
- steering
- brake
- accelerator
You do not need to know the engine’s internal working.
In Python, abstraction is often done using abstract classes.

Encapsulation in Python Programming
Encapsulation is one of the most important concepts in Object-Oriented Programming (OOP). It means bundling data and methods together inside a class and restricting direct access to the data from outside the class.
In simple words, encapsulation helps us protect data and control how it is accessed or modified.
1. What is Encapsulation?
Encapsulation means keeping the internal details of an object hidden and allowing access only through specific methods.
A class can contain:
- data → variables or attributes
- methods → functions that work on that data
The data is stored inside the class, and the outside world should not directly change it without permission.
2. Why Do We Use Encapsulation?
Encapsulation is used to:
- protect data from unwanted changes
- improve security
- keep code organized
- make programs easier to maintain
- control how data is accessed
- reduce complexity
It is very useful in real-world applications like:
- bank accounts
- student records
- login systems
- employee systems
- online shopping systems
3. Real-Life Example of Encapsulation
Think about a bank account.
You can:
- deposit money
- withdraw money
- check balance
But you should not directly change the balance from outside.
For example, you should not do this:
account.balance = -50000


That would be unsafe.
Instead, the bank gives you methods like:
- deposit()
- withdraw()
- get_balance()
This is encapsulation in practice.
4. Encapsulation in Python
Python does not enforce strict private data like some other languages, but it follows naming conventions to indicate whether data is public, protected, or private.
Python uses:
- public members
- protected members
- private members
5. Public Members
Public members are accessible from anywhere.
Example
class Student:    def __init__(self, name):        self.name = name


Here, name is public.
You can access it directly:
s1 = Student("Saurav")print(s1.name)


Output:
Saurav


Public members are not hidden.
6. Protected Members
Protected members are written with a single underscore _.
Example:
class Student:    def __init__(self, name):        self._name = name


This means:
- it should be treated as protected
- it should not be accessed directly from outside the class in normal practice
Python does not fully prevent access, but the underscore is a warning to programmers.
7. Private Members
Private members are written with double underscores __.
Example:
class Student:    def __init__(self, name):        self.__name = name


This means the attribute is meant to be hidden inside the class.
Direct access from outside is not recommended and usually not possible in the normal way.
8. Example of Encapsulation
class BankAccount:    def __init__(self, balance):        self.__balance = balance    def deposit(self, amount):        self.__balance += amount    def withdraw(self, amount):        if amount <= self.__balance:            self.__balance -= amount        else:            print("Insufficient balance")    def get_balance(self):        return self.__balanceaccount = BankAccount(1000)account.deposit(500)account.withdraw(300)print(account.get_balance())


Output
1200


Explanation
- __balance is private
- outside code cannot directly change it safely
- methods like deposit(), withdraw(), and get_balance() control access
9. How Encapsulation Protects Data
Encapsulation prevents direct modification of important data.
For example, if balance were public:
account.balance = -10000


This would break the rule of the bank account.
Encapsulation makes sure data changes only through controlled methods.
10. Encapsulation with Getter and Setter Methods
When data is private, we often use:
- getter methods to read data
- setter methods to change data
Getter
Used to access private data.
Setter
Used to update private data safely.
Example
class Student:    def __init__(self, name, age):        self.__name = name        self.__age = age    def get_name(self):        return self.__name    def set_name(self, name):        self.__name = name    def get_age(self):        return self.__age    def set_age(self, age):        self.__age = ages1 = Student("Saurav", 21)print(s1.get_name())print(s1.get_age())s1.set_name("Ram")s1.set_age(22)print(s1.get_name())print(s1.get_age())


Output
Saurav21Ram22


11. Benefits of Getter and Setter Methods
Getter and setter methods:
- allow controlled access
- prevent invalid values
- protect private data
- make code easier to update later
Example:
You can stop someone from setting age to a negative number.
def set_age(self, age):    if age > 0:        self.__age = age    else:        print("Invalid age")


12. Encapsulation and Data Hiding
Encapsulation is closely related to data hiding.
- Encapsulation means wrapping data and methods together.
- Data hiding means hiding the internal details from outside access.
They work together to make code safer and cleaner.
13. Encapsulation in a Student Class
class Student:    def __init__(self, name, marks):        self.__name = name        self.__marks = marks    def display(self):        print("Name:", self.__name)        print("Marks:", self.__marks)    def set_marks(self, marks):        if marks >= 0:            self.__marks = marks        else:            print("Marks cannot be negative")s1 = Student("Saurav", 85)s1.display()s1.set_marks(90)s1.display()

Name: SauravMarks: 85Name: SauravMarks: 90


14. Advantages of Encapsulation
Encapsulation has many advantages:
1. Data Protection
Sensitive data is protected from direct changes.
2. Better Control
You control how data is accessed or updated.
3. Easy Maintenance
If you want to change internal logic, you can do it inside the class without affecting outside code.
4. Improved Security
Private data is safer.
5. Cleaner Code
The program becomes more organized and understandable.
15. Disadvantages or Limitations
Encapsulation also has a few limitations:
- It may require more code
- It can make programs a little longer
- Beginners may find private variables confusing at first
Still, the benefits are much greater than the limitations.
16. Accessing Private Variables in Python
Although private variables are hidden by naming convention, Python still allows internal access through name mangling, but this is not recommended in normal programming.
Example:
class Student:    def __init__(self, name):        self.__name = name


This does not mean data is impossible to access, but it means it should not be accessed directly.
The correct way is to use getter and setter methods.
17. Encapsulation vs Abstraction
These two concepts are related but different.
Encapsulation
- wraps data and methods together
- controls access to data
Abstraction
- hides unnecessary details
- shows only important features
Example:
A bank account class uses encapsulation to protect balance, and abstraction to expose only deposit, withdraw, and balance check methods.
18. Example: Bank Account with Encapsulation
class BankAccount:    def __init__(self, name, balance):        self.__name = name        self.__balance = balance    def deposit(self, amount):        if amount > 0:            self.__balance += amount    def withdraw(self, amount):        if 0 < amount <= self.__balance:            self.__balance -= amount        else:            print("Invalid withdrawal")    def get_balance(self):        return self.__balance    def display(self):        print("Name:", self.__name)        print("Balance:", self.__balance)acc = BankAccount("Saurav", 5000)acc.deposit(2000)acc.withdraw(1500)acc.display()


Output
Name: SauravBalance: 5500


19. Common Beginner Mistakes
Mistake 1: Using private variable directly
Wrong:

Better:

Mistake 2: Not validating input in setter
If you allow invalid values, encapsulation loses its purpose.
Mistake 3: Thinking private means completely inaccessible
In Python, privacy is mostly based on convention and name mangling, not strict blocking.


Inheritance in Python Programming
Inheritance is one of the most important concepts in Object-Oriented Programming (OOP). It allows one class to reuse the properties and methods of another class.
In simple words, inheritance means:
A child class can get features from a parent class.

This helps us avoid writing the same code again and again.
1. What is Inheritance?
Inheritance is a mechanism in which a new class acquires the properties and behaviors of an existing class.
- The existing class is called the parent class or base class
- The new class is called the child class or derived class
Example idea
A Person class may contain:
- name
- age
A Student class may also contain:
- roll number
- marks
Instead of writing name and age again inside Student, we can inherit them from Person.
2. Why Do We Use Inheritance?
Inheritance is useful because it:
- saves time
- reduces code duplication
- improves code reuse
- makes programs easier to maintain
- helps build relationships between classes
- makes code more organized
3. Basic Syntax of Inheritance
class ParentClass:    # parent class codeclass ChildClass(ParentClass):    # child class code


The child class is written with the parent class name inside parentheses.
4. Simple Example of Inheritance
class Person:    def __init__(self, name):        self.name = name    def show(self):        print("Name:", self.name)class Student(Person):    passs1 = Student("Saurav")s1.show()


Output
Name: Saurav


Explanation
- Person is the parent class
- Student is the child class
- Student inherits the show() method from Person
5. Important Terms in Inheritance
Parent Class
The class whose features are inherited.
Child Class
The class that inherits features from the parent class.

6. How Inheritance Works
When a child class inherits from a parent class:

- it can use them directly
- it can also add new attributes and methods of its own
So inheritance helps create a hierarchy of classes.
7. Types of Inheritance in Python

1. Single Inheritance
2. Multiple Inheritance

- This is called multiple inheritance

- B and C both inherit from A
12. Hybrid Inheritance
Hybrid inheritance is a combination of two or more types of inheritance.

- hierarchical inheritance

Polymorphism in Python Programming
Polymorphism is one of the most important concepts in Object-Oriented Programming (OOP). It means many forms.
In Python, polymorphism allows the same function, method, or operator to behave differently depending on the object or data type being used.
1. What is Polymorphism?
The word poly means many and morphism means forms.
So, polymorphism means:
One thing can take many forms.

In programming, this means the same name can be used for different behaviors.
For example:
- a sound() method can behave differently for a Dog and a Cat
- the + operator can add numbers and also join strings
2. Why Do We Use Polymorphism?
Polymorphism is useful because it:
- makes code flexible
- improves code reusability
- reduces complexity
- makes programs easier to understand
- supports real-world behavior
It helps us write cleaner and more powerful programs.
3. Simple Idea of Polymorphism
Think about the word “start”.
- A car starts differently
- A bike starts differently
- A computer starts differently
The word is the same, but the action is different.
This is polymorphism.
4. Types of Polymorphism in Python
Python commonly supports polymorphism in these ways:
1. Method Overriding
2. Operator Overloading
3. Function Polymorphism
4. Duck Typing
5. Method Overriding
Method overriding happens when a child class provides its own version of a method that already exists in the parent class.
The method name is the same, but the behavior changes.
Example
class Animal:    def sound(self):        print("Animal makes a sound")class Dog(Animal):    def sound(self):        print("Dog barks")class Cat(Animal):    def sound(self):        print("Cat meows")d = Dog()c = Cat()d.sound()c.sound()


Output
Dog barks
Cat meows

Explanation
- Animal has a sound() method
- Dog overrides sound()
- Cat also overrides sound()
Same method name, different behavior.
6. Operator Overloading
Operator overloading means the same operator works differently depending on the operands.
For example, the + operator can:
- add numbers
- concatenate strings
- join lists
Example 1: Numbers
print(10 + 5)


Output:
15

Example 2: Strings
print("Python" + " Programming")


Output:
Python Programming

Example 3: Lists
print([1, 2] + [3, 4])


Output:
[1, 2, 3, 4]

The same operator behaves differently based on the type of data.
7. Function Polymorphism
Python built-in functions can work with different data types.
For example, len() works on:
- strings
- lists
- tuples
- dictionaries
Example
print(len("Python"))print(len([1, 2, 3]))print(len((10, 20, 30)))


Output
6
3
3

The same function len() works on different objects.
8. Duck Typing
Python follows a principle called duck typing.
The idea is:
If it looks like a duck and sounds like a duck, then it is treated like a duck.

In Python, the type of an object matters less than the behavior it supports.
If an object has the required method, Python can use it.
Example
class Dog:    def speak(self):        print("Bark")class Human:    def speak(self):        print("Hello")def make_sound(obj):    obj.speak()d = Dog()h = Human()make_sound(d)make_sound(h)


Output
Bark
Hello

Explanation
Both objects have a speak() method, so the function works with both.
9. Real-Life Example of Polymorphism
Imagine a payment system.
You can pay using:
- card
- mobile wallet
- bank transfer
The action is the same: pay
But the method is different.
That is polymorphism in real life.
10. Polymorphism with Classes
Example
class Bird:    def fly(self):        print("Bird can fly")class Eagle(Bird):    def fly(self):        print("Eagle flies high")class Penguin(Bird):    def fly(self):        print("Penguin cannot fly")birds = [Eagle(), Penguin()]for bird in birds:    bird.fly()


Output
Eagle flies high
Penguin cannot fly

Explanation
The same method fly() behaves differently in different classes.

Polymorphism is often used with inheritance.
A parent class defines a common method, and child classes modify it according to their own behavior.
Example

12. Advantages of Polymorphism
Polymorphism provides many benefits:
1. Code Reusability
The same function name can be used in different situations.
2. Flexibility
Programs can handle different data types and objects easily.
3. Cleaner Code
You do not need many separate function names for similar behavior.
4. Easy Expansion
New classes can be added without changing existing code much.
5. Real-World Modeling
It matches real-life behavior more naturally.
13. Polymorphism vs Inheritance
These two concepts are related but different.
Inheritance
- one class gets features from another class
Polymorphism
- the same method or operator behaves differently in different situations
Example:
A Dog and a Cat may both inherit from Animal, but each can define its own sound() method.
Inheritance gives the relationship. Polymorphism gives the different behavior.

Abstraction in Python Programming
Abstraction is one of the most important concepts in Object-Oriented Programming (OOP). It means hiding unnecessary details and showing only the essential features to the user.
In simple words:
Abstraction lets you use something without needing to know how it works internally.

For example, when you use a mobile phone, you know how to make a call, send a message, or open an app. But you do not need to know the internal circuit design or processor logic. That hidden complexity is abstraction.
1. What is Abstraction?
Abstraction is the process of:
- hiding internal implementation details
- showing only important features
- reducing complexity
- making code easier to use
It helps us focus on what an object does, rather than how it does it.
2. Why Do We Use Abstraction?
Abstraction is useful because it:
- hides complexity
- makes programs easier to understand
- improves code security
- reduces confusion
- makes code easier to maintain
- helps build large applications cleanly
It is especially useful in:
- banking systems
- payment systems
- car controls
- software libraries
- APIs
3. Real-Life Example of Abstraction
Think about a car.
When you drive a car, you use:
- steering wheel
- brake
- accelerator
- gear
You do not need to know:
- how the engine works internally
- how fuel is converted into motion
- how the electrical system is connected
You only use the important controls.
That is abstraction.
4. Abstraction in Python
In Python, abstraction is commonly implemented using abstract classes and abstract methods.
Python provides the abc module for this purpose.
abc means Abstract Base Class.
5. Abstract Class
An abstract class is a class that cannot be directly instantiated.
It is used as a base class for other classes.
It usually contains one or more abstract methods.
A child class must implement those methods.
6. Abstract Method
An abstract method is a method that is declared in an abstract class but does not have a complete implementation.
The child class must provide the actual implementation.
7. Why Use Abstract Classes?
Abstract classes are used to:
- define a common structure for child classes
- force child classes to implement certain methods
- ensure consistency in design
- support abstraction in OOP
8. Syntax of Abstract Class in Python
from abc import ABC, abstractmethodclass ClassName(ABC):    @abstractmethod    def method_name(self):        pass


Explanation
- ABC is the base class for abstract classes
- @abstractmethod is a decorator used to define abstract methods
- pass means the method has no implementation yet
9. Simple Example of Abstraction
from abc import ABC, abstractmethodclass Animal(ABC):    @abstractmethod    def sound(self):        pass


Here:
- Animal is an abstract class
- sound() is an abstract method
You cannot create an object directly from Animal.
10. Implementing Abstract Class in Child Class
from abc import ABC, abstractmethodclass Animal(ABC):    @abstractmethod    def sound(self):        passclass Dog(Animal):    def sound(self):        print("Dog barks")d = Dog()d.sound()


Output
Dog barks


Explanation
- Animal defines the abstract method sound()
- Dog provides the actual implementation
- So Dog can be instantiated
11. Why Can’t We Create Object of Abstract Class?
Abstract classes are incomplete.
They are meant to be inherited, not directly used.
Example:
from abc import ABC, abstractmethodclass Animal(ABC):    @abstractmethod    def sound(self):        passa = Animal()


This gives an error because Animal has an abstract method that is not implemented.

These two concepts are related but not the same.

- shows only essential features
Encapsulation
- bundles data and methods together
- protects data from direct access
Simple difference
- Abstraction = hide complexity
- Encapsulation = hide data
15. Example to Understand Difference
